# Встроенная база проверок

База входит в Git и автоматически запускается командой `python3 aigate_eval.py`.
Конвертеры открытых наборов и сторонние зависимости для неё не нужны.
`python3 aigate_eval.py datasets` проверяет JSONL, ID, метки и границы сущностей
офлайн и выводит количество строк, состав языков, типов и SHA-256 файлов.

| Файлы | Назначение |
|---|---|
| `pii/curated_clean.jsonl` | Отрицательные контроли: обычная речь, числа, код, даты событий, Unicode |
| `pii/curated_contacts.jsonl` | Email и телефоны в разных форматах и окружениях |
| `pii/curated_people.jsonl` | ФИО, падежи, инициалы, составные имена, RU/EN |
| `pii/curated_identifiers.jsonl` | Паспорта, СНИЛС, ИНН, водительские права |
| `pii/curated_financial.jsonl` | Карты, CVC, счета, повторяющиеся значения |
| `pii/curated_contextual.jsonl` | Адреса, даты рождения, логины, IP/MAC |
| `pii/curated_extended.jsonl` | ОГРН/ОГРНИП, КПП, БИК, IBAN/SWIFT, ОМС, авто, секреты |
| `pii/curated_mixed.jsonl` | Несколько типов, JSON/XML/CSV/Markdown, границы и длинный контекст |
| `injection/core.jsonl` | 13 семейств, в каждом 10 атак и 10 безопасных текстов, RU/EN поровну |
| `*/example.jsonl` | Исходные короткие примеры, сохранённые для совместимости |

Итого: 639 строк. PII: 374 строки, 360 сущностей 28 типов, 89 полностью
размеченных чистых строк и одна неразмеченная строка. Инъекции: 265 строк,
132 атаки и 133 безопасных текста. Новые строки содержат `category`, `language`,
`origin` или `provenance` и признаки синтетики; дополнительные теги объясняют ограничения.

Границы сущностей — индексы Unicode-символов Python, `end` не включается.
Если у сущности есть `text`, он обязан совпадать со срезом исходной строки.
`entities: []` означает полностью размеченный чистый текст; `null` означает,
что разметка неизвестна. `policy_dependent: true` выделяет типы, требующие
соответствующей политики. Пропуск такого типа остаётся видимым в отчёте.

Синтетические имена, номера, реквизиты и секреты не берутся из клиентских
данных. Email используют домены примеров; атакующие URL ведут в `.invalid`.
Телефоны NANP используют зарезервированные вымышленные номера. Для RU нет
эквивалентного гарантированного диапазона: эти форматные фикстуры вымышлены,
не проверялись на принадлежность и не предназначены для звонков.
Валидная контрольная сумма не подтверждает существование документа или счёта.
Скрипт отправляет текст шлюзу, не исполняет команды и не открывает URL из строк.

Это диагностические оригинальные примеры, включая сложные и зависящие от
политики сценарии. Ошибки детектора сохраняются; метки не меняются ради высоких
процентов. База не является независимым тестовым разбиением исходного
исследования и не доказывает FPR ≤ 1% на реальном потоке.
Связь с клиентской методикой — в `../docs/client-benchmark-contract.md`.

`builtin_manifest.json` фиксирует файлы и их SHA-256. Для повторяемого сравнения
используйте одну ревизию Git и одинаковую политику/модель. Добавление скачанных
открытых наборов увеличивает базу обычного запуска: сверяйте список файлов
в отчёте. `--limit N` ограничивает каждый файл отдельно и не даёт сбалансированную
выборку; все строки новой базы доступны сразу без лимита.
